# Runtime resource license source

`CC-BY-SA-4.0.txt` is the unmodified official Creative Commons legal code from
[the Creative Commons source repository](https://github.com/creativecommons/creativecommons.org/blob/main/docroot/legalcode/by-sa_4.0.txt).
Its SHA-256 is `28a9529c7d0bb4dc51f4bf5c116a3d16ef247a052f7591466768ddf563fd1cf5`,
identical to the license pin in PdfCraft 0.13.0's `ATTRIBUTION.toml`.
It accompanies the two unmodified local OCR resources. Keeping this small public
license text in the integration avoids a build dependency on a web page that
returns HTTP 403 to the build hosts. Resource authors, sources and attribution
remain in the locked upstream manifest and packaged model attribution.
